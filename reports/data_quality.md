    | Column | dtype | Null rate | Meaning |
    |---|---|---|---|
    | `tweet_id` | int64 | 0.0% | Unique integer ID for each tweet |

    ## Known Issues & Handling

    - `in_response_to_tweet_id`: 553 NaN values (root tweets have no parent — expected)
- `response_tweet_id`: stored as string because values can be comma-separated lists (e.g. '5,7') when a tweet has multiple replies
